# rst2pdf

## Environments

Check uv version.

```sh
uv --version
```

```text
uv 0.11.28 (x86_64-unknown-linux-gnu)
```

## Run

Create document.

```sh
uv run rst2pdf -s style.yml <path/to/file>.rst
```
