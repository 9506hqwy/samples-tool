# gitignore ファイル

git リポジトリの管理対象外にするファイルを指定する。

すでに管理状態のファイルには効果がない。

## ファイルの場所

ファイルは下記に配置する。ファイルの優先順位は記載の通りとなる。

- *.gitignore*
- *$GIT_DIR/info/exclude*
- *$XDG_CONFIG_HOME/git/ignore* (*$HOME/.config/git/ignore*)

リポジトリにあるファイルと同じディレクトリからリポジトリのルートディレクトリまで辿って、
各ディレクトリにある *.gitignore* ファイルが適用対象になる。

## パターン設定

1 行で管理外にするパターンを指定する。

複数の *.gitignore* ファイルが適用される場合は下位ディレクトリかつ最後に一致するパターンが適用される。

### コメント

行頭を `#` から始める。パターンに使用する場合は `\` でエスケープする。

### 否定

パターンの先頭を `!` にすると一致したファイルは管理対象とする。
ただし、管理対象外の親ディレクトリにあるファイルに対しては効果がない。

### ディレクトリ

パターンの末尾が `/` の場合はディレクトリと一致する。
`/` がない場合はファイルとディレクトリに一致する。

末尾の `/` を除いて `/` を含むパターンは *.gitignore* からの相対パスを指定する。
そのため末尾以外に `/` がある場合は先頭の `/` は意味がない。

### ワイルドカード

|         | 説明                           |
| :-----: | :----------------------------- |
|   `*`   | `/` 以外の 0 文字以上の文字列  |
|   `?`   | `/` 以外の 1 文字              |
| `[...]` | 含まれる文字列                 |
|  `**`   | すべてのディレクトリとファイル |
