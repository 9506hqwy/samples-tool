# status コマンド

リポジトリの状態を確認する。

```sh
jj status
```

```text
The working copy has no changes.
Working copy  (@) : qqzvonsz 99e43872 (empty) (no description set)
Parent commit (@-): zzzzzzzz 00000000 (empty) (no description set)
```

qqzvonsz/zzzzzzzz は「change ID」, 99e43872/00000000 は「commit ID」となる。
00000000 のコミットは「root commit」となる。
